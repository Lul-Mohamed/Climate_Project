# Climate Data Analysis Project

## Overview
This project focuses on climate data analysis
using Python.

## Objectives
- Analyse rainfall observations.
- Calculate total rainfall.
- Calculate average rainfall.
- Develop climate monitoring products.

## Tools and Technologies
- Python 3.12
- Conda
- Pandas
- NumPy
- Matplotlib
- Git
- GitHub

## Project Files
- environment.yml: Python environment configuration.
- rainfall.py: First rainfall analysis script.
- .gitignore: Files excluded from Git tracking.

## How to Run

1. Create the environment:

   conda env create -f environment.yml

2. Activate the environment:

   conda activate climate_env

3. Run the script:

   python rainfall.py
